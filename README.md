# Delish Restaurant Website

A responsive single-page restaurant website for **Delish**, built from the brand guide and mockups (terracotta `#CB3A1A`, Jost + Archivo typography).

## Run locally

```bash
cd website
python -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Project structure

- `website/index.html` — main page
- `website/css/styles.css` — styles
- `website/js/main.js` — slider, menu filters, forms
- `website/images/` — local photos (hero, menu, gallery, etc.)
