# Delish Restaurant Website

A responsive single-page website built from the **Delish** brand guide and mockups in your PDF.

## Brand colors

| Role | Hex |
|------|-----|
| Primary | `#CB3A1A` |
| Secondary | `#111111` |
| Body text | `#74787C` |
| White | `#FFFFFF` |

## Fonts

- **Headings:** Jost (Google Fonts)
- **Body:** Archivo (Google Fonts)

## Images

All photos are stored locally in `images/` (hero slides, menu items, gallery, blog, services, and more). The site works offline once images are downloaded.

## Open locally

1. Open `index.html` in your browser, or
2. Run a local server from this folder:

```bash
python -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Structure

- `index.html` — page content and sections
- `css/styles.css` — layout and brand styling
- `js/main.js` — hero slider, menu filters, gallery, forms
- `images/logo.svg` — Delish logo mark
